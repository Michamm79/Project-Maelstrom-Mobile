# This directory targets the wrong engine

The game design document describes **Unreal Engine 5.8, C++ and Blueprint**.
This tree is C# for Unity.

It exists because the mobile build was first ported from a repository of Unity
`OrbSystem` scripts, which turned out to be a separate, earlier prototype rather
than the project the GDD describes. The mechanic those scripts implement -
combining two materials into a third, called "transmutation" - is not in canon
and no longer exists anywhere else in this repository.

**What is still current here**

- `Assets/Scripts/Content/ContentSchema.cs` and `ContentDatabase.cs` mirror the
  generated bundle and read it. They are kept so the guarantee this directory
  was built for - that both runtimes read identical content - still holds.
- `Assets/Resources/maelstrom-content.json` is generated by
  `npm run build:content` and is current.

**What is stale**

Everything else under `Assets/Scripts` - the orb container, the transmutation
and alchemy systems, the material and recipe ScriptableObjects, the HUD and the
zone spawner. They implement the prototype's design: orbs as storage, a
pair-combination recipe tree, level-gated zones. Canon has none of those.

**Recommendation**

Delete this directory. If a bridge to the PC build is wanted, the useful form is
an Unreal-friendly export of the same content bundle, not a Unity mirror. Left
in place pending that decision rather than removed unilaterally.
